# LANDEX BEACON（L-Beacon）

営業部・総務部・管理部・不動産事業部の報告・相談アプリ。GAS＋Googleスプレッドシートで動くWebアプリ。
社員が書いた相談を、Todoistの各部署の「📥社長がやる」に1件1タスクで起票する。社長の回答はこれまでどおり Todoist と Claude で行う。

- `gas/` … GASのコード（フェーズ1：報告の入力・保存・Todoist起票・自動の起票し直し）
- `mock/` … 画面のモック（`python3 mock/build.py` で部署ごとのHTMLを作る）

## 設置の手順（藤本さんのGoogleアカウントで行う）

1. https://script.google.com で「新しいプロジェクト」を作り、名前を「LANDEX BEACON」にする。
2. 左の歯車「プロジェクトの設定」で「『appsscript.json』マニフェスト ファイルをエディタで表示する」にチェックを入れる。
3. エディタに次のファイルを作り、`gas/` の同じ名前のファイルの中身をそのまま貼り付ける。
   - スクリプト（＋ → スクリプト）：`Config` `Util` `Todoist` `Report` `Retry` `Main` `Setup`（最初からある `コード.gs` は消す）
   - HTML（＋ → HTML）：`Index` `Css` `Js`
   - `appsscript.json` は、すでにあるものを丸ごと置き換える
4. 「プロジェクトの設定」→「スクリプト プロパティ」に次を追加する。
   - `TODOIST_TOKEN`：Todoistの「設定 → 連携機能 → 開発者」にあるAPIトークン
5. エディタの上で関数 `LB_setup` を選んで「実行」。権限の確認が出たら許可する。
   - スプレッドシート「LANDEX BEACON データ」が藤本さんのドライブにでき、30分ごとの起票し直しが設定される。
   - モードは `test`（テストモード）になる。
6. 関数 `LB_checkSetup` を実行し、実行ログに `OK` が6行（5部署＋BEACONテスト）出ることを確認する。Todoistには何も書き込まない。
7. 右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」。
   - 次のユーザーとして実行：自分（fujimoto@landex-ltd.com）
   - アクセスできるユーザー：landex-ltd.com 内の全員
   - 出てきた `/exec` のURLを開く。

コードを直したときは、貼り付け直したあと「デプロイ」→「デプロイを管理」→ 編集（鉛筆）→ バージョン「新バージョン」で更新する（URLは変わらない）。

## モード

| スクリプト プロパティ `LB_MODE` | 使える人 | 起票先 |
|---|---|---|
| `test`（初期値） | 藤本さんだけ | すべて Todoist「BEACONテスト」 |
| `live` | 社員7人（藤本さんも可） | 社員は各自の部署。藤本さんの送信は常に「BEACONテスト」 |

藤本さんが開くと、画面の上で「どの報告者として入力するか」を選べる。部署ごとの入力欄を試すためのもの。

## フェーズ1で確かめること

1. 各報告者を選んで送り、Todoist「BEACONテスト」の 📥社長がやる にタスクが出るか。
2. タイトル・説明欄・ラベル `📥社長がやる`・優先度 p1・期限が正しいか。担当者が藤本さんになっているか（BEACONテストは共有していないプロジェクトなので、担当者を付けられない場合は担当者なしで起票し、スプレッドシートの「エラー」欄にそう書く。本番の部署プロジェクトでは必ず藤本さんが担当）。
3. タスクの最初のコメントに、その日の日報が付いているか。
4. 社長回答コメントスキルが、このタスクをいつもどおり読めるか（【誰に返すか】を通知先に使えるか）。
5. 共有のみの相談は起票されず、スプレッドシートにだけ残るか。
6. スプレッドシートの「報告」「相談」シートに1件1行で残るか。

## 起票に失敗したとき

- 報告はスプレッドシートに必ず残る。相談の行の「状態」が `起票失敗` になる。
- 30分ごとに自動で起票し直す。送信時を含めて4回失敗したら、藤本さんにメールする（1件につき1回だけ）。
- 起票できたのに列が 📥社長がやる になっていない場合は、状態が `要確認` になり、同じくメールで知らせる。
- 原因を直したあと、「相談」シートの該当行の「試行回数」を `0` にすると、30分以内にもう一度起票する。

## 会社の休み

期限が空欄の相談は、翌営業日を仮期限にする。土日と日本の祝日（Googleカレンダー「日本の祝日」）は自動で除く。
年末年始・夏季休暇などは、スプレッドシートの「会社休日」シートのA列に日付を入れる。
